⚙️ إعدادات النظام
🔥 كيفية تفعيل المزامنة الفورية
  1. اذهب إلى console.firebase.google.com
  2. افتح مشروع Medina Homestays → Realtime Database → أنشئ قاعدة بيانات
  3. اذهب إلى Project Settings → General → Your apps → Web
  4. انسخ الـ Config والصقه في الخانة أعلاه
  5. اضغط حفظ — ستتحول المزامنة للوضع الفوري تلقائياً

بدون Firebase: كل شيء يعمل على نفس الجهاز (localStorage). للمزامنة بين أجهزة مختلفة: Firebase ضروري.
